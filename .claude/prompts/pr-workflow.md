## PR Workflow

Use GitHub MCP to create and manage pull requests instead of manual git commands.

- Once a feature's changes are typechecked and build clean, use GitHub MCP to open a PR: create the branch 
  (if not already pushed), commit, push, and open the PR against `main`
- PR description should summarize what changed and reference the relevant prompt file(s) used for the task
- Do not merge — opening the PR is the final step; merging is manual
